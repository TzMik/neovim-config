# 🤝 Contributing to nvim-config

Thank you for your interest in contributing to my Neovim configuration.

**This repository is currently configured to accept feedback, suggestions for improvement, bug reports, and questions exclusively through the Issues section.**

Direct code contributions (Pull Requests) are currently not being accepted, as this is a personal configuration and I wish to maintain full control over the source code.

## 📝 How to Contribute (Issues)

If you would like to contribute, please use the **Issues** tab to:

* Report any errors (bugs) you encounter.
* Suggest an optimization or an interesting plugin.
* Ask questions about how a specific part of the configuration is set up.

I greatly appreciate your understanding and your valuable feedback.
